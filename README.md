# 把你做過的案子，變成可以賣的產品

顧問版知識庫指令總表。照順序貼進 WorkBuddy，全程不用寫程式。

| 頁面 | 內容 |
|---|---|
| [指令總表](index.html) | 20 張指令卡，0.1 到 7.1。**主要用這一份。** |
| [先把 Obsidian 裝起來](setup.html) | 10 分鐘的安裝與設定，第一次來先看這個 |

## 這一套在做什麼

```
1 案例  →  2 模式  →  3 產品  →  4 交付 ─┐
  ▲                                      │
  └────── 每次交付完，回流改進 1 ──────────┘
```

案例庫只有 **1**。少了 **2、3** 它是作品集不是產品；少了 **4** 回流，產品不會進化。

## 三句話護欄

只要那句指令**會動到你的檔案**：

```
先給我看　·　我說 OK 你才動　·　沒說到的不要碰
```
